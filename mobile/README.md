# TrAI Mobile App (Flutter)

Cross-platform iOS, Android, and Web application for TrAI — Trust-as-a-Service Platform.

## Features
- **Live Video / Speech Fact-Checker**: Real-time evaluation of political speeches and live broadcasts.
- **Incident Alerts**: Immediate notifications when high-severity propaganda or prompt-injection attempts are detected.
- **Multi-Language Intelligence**: Localized truth feeds for English, Russian, and Armenian speakers.
- **Offline Consensus Fallback**: Graceful local simulation when network is disconnected.

## Quick Start
```bash
# 1. Ensure Flutter 3.x+ is installed
flutter --version

# 2. Get dependencies
flutter pub get

# 3. Run on connected device, emulator, or Chrome
flutter run -d chrome
# or
flutter run -d android
```
